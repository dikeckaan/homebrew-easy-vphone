# Homebrew tap for easy-vphone

```sh
brew tap dikeckaan/easy-vphone
brew install --cask dikeckaan/easy-vphone/easy-vphone
```

Apple Silicon, macOS 15 or later. Version 0.2.0 is an Apple Development signed development preview, not a notarized Developer ID release. Gatekeeper may block the app on other Macs.

Source and release notes: https://github.com/dikeckaan/easy-vphone
